# 视频准备

本工具用于作者显式维护视频；course.pack自动复用编码与技术校验，在临时副本中准备成品，不修改原片。成品使用 MP4 容器、H.264 / yuv420p；保持画面比例，宽不超过 1280、高不超过 720，不放大小图，最高 30 帧，不把低帧率强制补成 30。竖屏也适用这一宽高上限，例如 1080×1920 会成为约 404×720。

默认 CRF 24、slow 预设，音频 AAC 96 kbps 双声道；无声视频保持无声。串行处理，每次编码用 2 个编码线程，避免并发转码占满作者机器。CRF 是质量参数，不承诺固定文件大小或码率；复杂画面仍可能很大，转换结果甚至可能比原片大，工具会报告这一情况。上传大小和平台验收限制仍以平台实际契约为准，本工具不新增服务器端视频校验。

## 调用

需要 Python 3.10+、带 libx264 的现代 FFmpeg 及 ffprobe。工具不安装、不下载依赖；缺失时返回错误。可用 PATH，也可显式传入可执行文件路径。

```powershell
# 默认只读取、探测和列出计划；不写文件。相对路径以调用目录为准。
python <Skill>/scripts/tools.py course.videos "D:\课程\assets"

# 转码到明确的课件临时目录，保留子目录结构。
python <Skill>/scripts/tools.py course.videos "D:\课程\assets" --apply --output "D:\课程\_scratchpad\video-720p"

# 也支持单文件；需要更清楚的小字时，可降低 CRF（文件通常更大）。
python <Skill>/scripts/tools.py course.videos "D:\原稿\演示.mov" --apply --output "D:\课程\_scratchpad\video-720p" --crf 22 --ffmpeg "D:\ffmpeg\bin\ffmpeg.exe" --ffprobe "D:\ffmpeg\bin\ffprobe.exe"
```

省略 `--output` 时使用输入文件所在目录或输入目录下的 `_scratchpad/video-720p/`。输出名为 `<完整原文件名>.720p.mp4`，保留原扩展名以区分同名的 MOV、MP4。递归扫描常见视频扩展名，跳过 Shared、`.git`、`node_modules`、`_scratchpad`、指定输出目录及符号链接/junction；显式输入或输出位于 Shared 也拒绝执行。

结果 stdout 为单份 JSON，进度写 stderr；执行或单文件错误返回 2，批量任务仍继续处理其他文件。已有输出一律报错，不覆盖，也不把旧文件当成本次成功；重跑时指定新的输出目录。失败和中断时删除本次未完成的临时结果，已完成文件和原片保留。工具通过源文件旋转及像素比例计算目标尺寸；成品先核验编码、尺寸、帧率、时长和音轨，再完整解码验证，最后原子创建正式输出。文件系统需支持同卷硬链接，否则该文件失败而不覆盖目标。

## 适用范围与交付

- 面向普通 SDR、不透明视频。HDR 需另行做色调映射；带透明通道的视频不能用 H.264 保留透明效果，已识别到这些输入时明确拒绝。非直角旋转也单独处理。
- 仅保留第一个视频画面和第一条音轨；多音轨会提示。字幕、章节、附件与其他元数据不写入成品。需要的字幕先单独纳入课程设计，不能依赖它们随视频保留。
- 不自动更改源码引用，不删除原片，独立调用不负责打包；course.pack默认复用本编码实现处理副本。工具不读取 `target-root.json`。
- 转码后查看代表性片段，核对密集文字、运动细节、画面方向、比例和声音同步；技术校验不能代替视觉验收。720p 小字不清楚时调整录屏字号、裁切或拆分内容，单独降低 CRF 未必能解决分辨率不足。
- 选定成品后复制到课程正式 `assets/`，在 TSX、CSS、JSON 中更新完整字面量路径。原片留在课程包外或适当临时位置，避免源片与成品同时交付；完成提升和引用核对后再按既有规则清理临时目录、打包。上传授权与打包规则保持原有边界。
- 实际压缩任务继续核对路径，不能以转码成功收尾。结果 `source` / `output` 为绝对路径；`source_relative` / `output_relative` 分别相对本次输入和输出根目录，不是自动生成的课件引用。`output_exists` 确认成品存在，`temporary_output` 标明是否仍在 `_scratchpad`，`reference_status` 提醒引用尚待核对。按映射提升选定成品到本课件正式 `assets/` 并确认字节一致，更新实际引用，搜索旧路径和旧文件名残留，追踪动态数据。课件引用使用 `/`，不得写本机绝对路径或 `_scratchpad`。分别报告路径静态检查与实际播放验证结果。

参数依据：[FFmpeg 帧率参数](https://ffmpeg.org/ffmpeg.html)、[MP4 faststart](https://ffmpeg.org/ffmpeg-formats.html)。本工具添加 `faststart`，将 MP4 索引移到文件前部，便于网页开始播放。
