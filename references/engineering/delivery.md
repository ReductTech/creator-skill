# 源码 ZIP 交付

## 一次调用

```powershell
python <Skill>/scripts/module/package_course.py <课程或工程目录> [其他目录]
# 同一入口
python <Skill>/scripts/tools.py course.pack <目录>
```

支持单课程、课程集合和工程根目录，基础打包无需全局绑定；深入检查按窗口配置、Node及本地Shuku运行时等实际能力执行。输出自动放在课程同级或工程的集合位置，不覆盖已有包与报告。工具不上传。

## 依赖与流水线

- 无媒体、无转换的源码可只用 Python 标准库。
- 图片需要 Pillow；原目录图片引用迁移优先复用原有 Node/TypeScript 规划器，直接修改原源码且不创建副本；不可用时使用 Python Tree-sitter，安装 `pip install -r <Skill>/scripts/requirements-pack.txt`。
- 有音视频才需要 FFmpeg（libx264/AAC）及 ffprobe；可传 `--ffmpeg <路径> --ffprobe <路径>`。不自动安装依赖。

流水线按同一清单执行：发现课程与源码检查 → 探测环境及已保存安装意愿 → 原目录转换图片并迁移引用 → 图片复验与适用的本地静态、类型、构建及浏览器检查 → ZIP归档及完整性核验。图片转换直接修改原工程，成功后删除原图，仅保留 WebP 和 SVG；不创建图片副本。所有尺寸的图片均处理，无法转换则报错阻止打包。音视频仍使用临时输出。

SVG 验证 XML 后原样保留。静态普通图片转换为 WebP q80，按固定宽1600、高900边界等比例缩小，不放大；已合规 WebP 保留。图集 `image-atlases/` 保持尺寸。动画保留帧、时长与循环，不静默变成静态图。缩略图和封面使用独立1600×900、q20规格；服务器仍重新生成正式预览。

视频复用本地工具的 MP4/H.264、最高1280×720/30fps、CRF24、AAC96kbps规则；独立音频为 M4A/AAC-LC96kbps。技术检查复用[视频](video-assets.md)与[音频](audio-assets.md)工具；HDR、透明视频、损坏或不支持素材报错，不丢失其语义后强行出包。仅保留首音轨会提醒，听感与画面质量仍需实际检查。

## 引用与智能体收尾

完整路径的 JS/TS/JSX/TSX 字符串由 Python AST 解析后迁移；JSON/glTF字符串、CSS url/import、HTML/XML/SVG资源属性和 Markdown链接按对应结构处理。保留查询参数、片段、换行与 BOM。不执行课程源码；原目录图片引用优先复用原有 Node AST 规划器，受限环境使用 Python AST 解析。

动态 helper 参数、模板拼接、歧义、目标冲突、语法错误和未覆盖引用须按报告核对。不能把退出成功说成完整运行验证。具体支持范围见[路径迁移](asset-paths.md)。不能证明安全改写的转换路径阻止出包；智能体在原源码中改成完整路径或固定路径列表，再调用同一入口。音视频临时输出仅在本次运行中存在，报告用课程内逻辑路径指向原源码，不返回已经删除的临时文件作为交付成果。

stdout 仅返回状态、统计、前20条问题、下一步和报告路径；省略问题数明确列出。完整 `.report.json` 保留全部转换源/目标、字节数、改引用记录、问题行号及覆盖范围；`.report.md` 便于阅读。失败也写报告，不生成残缺 ZIP。智能体按已有授权自动修复明确问题；只有内容取舍、质量选择或缺少外部条件时才询问。

## 文件规则与平台边界

课程保存为 `modules/<UUID>/`，平台默认 Shared 排除；明确登记的自定义风格保留在 `styles/`。缓存、`_scratchpad`、环境文件与黑名单文件不入包，原文件不删除。黑名单引用保留警告，不能把缺失依赖当作运行通过。`.py` / `.bin` 允许但标高风险；ELF/PE等危险内容不因改名或放 assets 获豁免。

非源码白名单文件超过100KiB须位于所属课件/风格 assets；单文件128MiB、总量1GiB、少于10000文件。身份、必要入口、UTF-8和完整性严重错误阻止整个请求出包，不自动缩小用户范围。

包不需要客户端证明或版本策略标签，Shuku 浏览器与隔离入库器独立复核实际路径、文件和图片，随后分类、安全检查及编译。标题默认值、空讲稿与稳定 UUID 依当前课程契约处理。上传/保存进入平台发布链路，正式缩略图和内容审核另行执行；本地脚本不宣称这些检查已通过，也不自动上传。

修复动态引用时，先在作者源码中枚举原工程实际存在的完整输入路径；course.pack会在原源码中改为成品路径。不要把临时副本中的目标路径提前写进没有该文件的原工程。

本地默认按环境启用全部适用检测，不把可执行检查统一留给服务器。缺依赖只问一次并持久化；多窗口使用独立目标配置，见[本地环境与窗口](local-environment.md)。有音视频就处理，没有则不调用FFmpeg。
