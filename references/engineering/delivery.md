# ZIP 源码交付

运行一次 `python <Skill>/scripts/module/package_course.py <输入目录> [更多目录]`，或 `tools.py course.pack <目录>`。输出普通 `.zip` 和同级 JSON/Markdown 报告；不要求客户端清单、流程标记或 SKZIP。无需 Node、Shuku 工程、本地构建或截图，不上传。

## 输入和内容

支持单模块、集合和工程目录。课程保留 `modules/<UUID>/` 结构，平台 Shared 自动排除，不覆盖或修改原工程。网页或服务器发现随包 Shared 将拒收：无需上传 Shared，请仅单独打包课程模块。自定义风格按已有登记收集。

源码、元数据、身份、必要入口、UTF-8、文件大小和黑名单按工具实际规则检查。黑名单文件从包中排除并逐项警告，原文件不删除；危险文件头不能靠改名或放入 assets 绕过。非白名单文件大于 100 KiB 须放在所属 assets；单文件 128 MiB、总量 1 GiB、少于 10000 文件。`.py`、`.bin` 保留高风险提醒，不代表安全通过。

## 图片

仅允许 SVG、WebP，检查真实格式和后缀。SVG 校验 XML 结构与 SVG 根节点，原样保留字节、文件名和引用，不转换为 WebP、不栅格化；此检查不代表服务器代码安全审核通过。WebP 完整解码，单帧最多 4000 万像素，动画最多 1000 帧。GIF、PNG、JPEG 等其他图片格式、伪装格式、损坏图片阻止出包；作者须将其他格式转换为 WebP 并同步引用，动画需保留动画效果。只读检查，不转换格式、不缩放、不改名、不迁移源码引用；作者负责准备正确文件与引用。缺少 Pillow 时明确失败，不跳过图片检查。

## 浏览器和服务器

网页在本机解包检查，逐项显示 ✓／？／✕；检查完且无叉才允许提交到私有 OSS。普通资源缺失或动态引用无法确认是提醒，平台不代修。服务器隔离解压并独立复核，随后 QEV 分类和提交代码安全检查，再执行平台技术检查、构建和发布；缩略图和内容审核沿用发布后的独立任务。

SHA-256 素材入库、去重、原相对路径到对象键的清单、授权访问、源码下载和离线包组装继续保留。作者不填写哈希或 OSS 地址。取消的只是图片转码及其引用迁移。

严重错误阻止出包；警告逐项说明影响、修复和复验方式。原工程不修改，工具不自动上传。下载工程可能包含平台依赖，再次上传时仍只打包课程模块。
